# Probability of Default Model for Italian Bank

## Overview
This project involves building a robust **Probability of Default (PD) Model** for an Italian bank. The model processes over 1 million raw financial records, transforming them into explainable financial ratios. It benchmarks interpretable machine learning models and evaluates their robustness using walk-forward testing and bootstrap AUC variance analysis. The final model is calibrated to align predicted PDs with empirical default rates, making it ready for deployment.

### Key Features
- **Data Preprocessing**: Cleaning and transforming raw financial data into smoothened financial ratios.
- **Model Benchmarking**: Evaluating interpretable ML models for robustness and performance.
- **Calibration**: Aligning predicted probabilities with empirical default rates.
- **Deployment-Ready**: Producing calibrated PD predictions for real-world use.

## Project Structure
```
project/
│
├── harness.py                  # Coordinates the full scoring pipeline for out-of-sample predictions
├── estimator.py                # Processes bank data, trains the model, and generates preprocessing/model files
├── predictor.py                # Generates and exports model predictions for new data
├── preprocessor.py             # Cleans and transforms raw financial data for predictions
├── meta_data_for_lowess_final.pkl
├── median_imputer_by_legal_struct_ateco_sector.pkl
├── full_gam_model.pkl
├── requirements.txt
├── calibration_metadata.pkl
└── README.md
```

### Component Details
- **`estimator.py`**: This script is responsible for processing the raw bank data and applying all necessary transformations to prepare the data for model training. It generates the `.pkl` files (e.g., `meta_data_for_lowess_final.pkl`, `median_imputer_by_legal_struct_ateco_sector.pkl`, `full_gam_model.pkl`, and `calibration_metadata.pkl`) that store the preprocessing parameters, model metadata, and calibration details. These files are later used by the `preprocessor.py` and `predictor.py` scripts to preprocess new data and make predictions.
- **`harness.py`**: Acts as the main pipeline for out-of-sample predictions. It loads the preprocessing parameters and model files generated by `estimator.py` and applies them to new data.
- **`preprocessor.py`**: Handles the cleaning and transformation of raw financial data into model-ready features using the preprocessing parameters stored in the `.pkl` files.
- **`predictor.py`**: Uses the trained model and calibration metadata to generate and export probability of default predictions for new data.

## Installation

### Prerequisites
- Python 3.8 or higher
- pip (Python package installer)

### Steps
1. Clone the repository:
   ```
   git clone <repository_url>
   cd <repository_folder>
   ```
2. Install the required Python packages:
   ```
   pip install -r requirements.txt
   ```
3. Download the dataset:
   - The dataset is not included in the repository. You can download it from [Dataset Source Link] or request access from the project owner.
   - Place the dataset in the `data/` folder within the project directory.

## Usage

### Generating Preprocessing and Model Files
To generate the preprocessing parameters and model files (`.pkl` files), run the `estimator.py` script:
```bash
python estimator.py --input_csv <training_data> --output_dir <output_directory>
```
- Replace `<training_data>` with the path to your training dataset CSV file.
- Replace `<output_directory>` with the directory where the `.pkl` files should be saved.

### Generating PD Predictions
To execute the harness and generate PD predictions:
```bash
python harness.py --input_csv <input_file> --output_csv <output_file>
```
- Replace `<input_file>` with the path to your input CSV file.
- Replace `<output_file>` with the desired name for the output CSV file.
